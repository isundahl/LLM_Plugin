# Bundled Pocket TTS reference voices

These small reference recordings are staged as NonUFS runtime files and can be
selected with plugin-relative paths:

| Voice ID | Path | Presentation |
| --- | --- | --- |
| `pocket-caro-davy` | `Plugin:/Content/Voices/pocket-caro-davy.wav` | Female |
| `pocket-bill-boerst` | `Plugin:/Content/Voices/pocket-bill-boerst.wav` | Male |

Both recordings come from the Voice-Zero selection in Kyutai's `tts-voices`
repository and are released under CC0. CC0 does not require attribution, but
the plugin retains this provenance:

- Source: https://huggingface.co/kyutai/tts-voices/tree/main/voice-zero
- Collection documentation: https://huggingface.co/kyutai/tts-voices
- License declaration: Voice-Zero recordings are released under CC0

Do not replace these files with EARS or Expresso recordings in a commercial
distribution. Those collections are CC BY-NC 4.0.
